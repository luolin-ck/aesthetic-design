# 1.0.0 — 首次版本化发行

## 问题与范围

原技能包没有版本或变更日志，完整性校验器却接受了未版本化状态。若整体公开研究素材库，还会再分发受限制、NC 或权利不明的媒体。此前研究是未版本化基线，不重建历史测试或版本。

## 逻辑改动与验收

- 新增 VERSION、匹配的 SKILL/manifest 元数据、双语变更日志和逐次记录，以及先测后改的维护约定。
- 扩展两份逻辑相同的离线校验器，增加可用性与发行检查，保留文件/哈希/链接/指南/翻译/图片完整性检查。
- 新增六项标准库变异测试：版本递增、缺版本/日志、陈旧元数据/无效 Red 证据、公开图缺失/未批准图片、受限制/NC 媒体，以及秘密/路径/符号链接拒绝。
- 分离完整私人版（43图）与保守公开版（9图，34图明确未附）。保留全部36份文字指南及43条来源记录；公开版仅8个方向有离线图片，28个方向缺图。
- 新增原创 MIT 范围和第三方说明、精确媒体权利决定、来源/署名保留及隐私/禁入文件检查。保留椅子图片嵌入的 Beatrice Pinto 署名，不推断其角色。

## 真实 Red 证据 — 2026-11-06

实现前，基线 `python3 scripts/validate_offline.py` 返回0，报告208文件/36方向/43图，尽管 VERSION 与 CHANGELOG 都不存在。新增验收预期拒绝（非0），实际断言于 UTC 04:53:48 以退出码1失败。这证明的是元数据缺陷，不是视觉风格错误。原始结果摘要见 JSON 对应文件。随后编写的变异测试最初因检查器尚未存在而导入失败；这只是实现顺序证据，不是另一项语义缺陷。

## 真实 Green 证据 — 2026-11-06

共享检查器实现后，`python3 -B -m unittest discover -s tests -v` 运行全部六项变异测试并返回0。最终完整技能包检查还对每个发行版运行两种语言校验器，只读并禁用 socket 访问。首轮完整检查中，私人版通过，报告222个清单文件、44组翻译、43图、1684条本地链接；公开版通过，报告189个清单文件、44组翻译、9图、1662条本地链接。文档修改后会再次运行最终检查；数量由校验器报告，不作为鉴真或分类基准。元数据检查器无法证明证据真实，仍须人工核对实际输出。未增加托管工作流或依赖。

## 限制与回退

自动检查验证元数据、可用性、字节及拒绝边界，不验证法律清权或风格准确性。首次公开允许清单有意保守，28个方向缺少本地视觉参照。未测试实际 Codex/Claude 激活、受控分类实验或全球法律清权。脚本不获取缺失文件。实现前保留了此前完整私人压缩包；回退时恢复已验证的完整版本或后续 Git tag 并重新验证，同时保留本记录。实现阶段没有改变公开仓库或外部状态。
