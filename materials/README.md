# Reviewed Real-work Material Library

> **Public distribution availability:** This is the conservative public edition: 9 bundled images, 34 withheld, with 28 of 36 directions lacking local visual comparators. Historical visual-review notes below describe earlier inspected source images, not a claim that withheld images are present or newly inspected. Check `availability` in catalog/records and the [publication policy](publication-policy.json). Do not download missing files automatically or infer visual confirmation from text.

This public edition retains **43 provenance/analysis records for 36 design directions but bundles only 9 real images across 8 directions**. **34 images are explicitly withheld; 28 directions have no public offline visual comparator**. The two weak background images were removed after the full selection review. No image was generated or redrawn by this package.

Start with the [per-image selection review](selection-review.md), [correspondence review](correspondence-review.md), [catalog](catalog.json) and [rights/provenance](provenance-and-rights.md). The [manifest](manifest.json) covers integrity, not historical truth or classification accuracy.

## Read the role first

- `style_reference`: use only for the record’s specified medium, branch and claim. It is neither an exclusive label nor a universal template.
- `context_only`: historical/site/method background; do not use it alone to establish stylistic membership.
- In catalog.styles, reference_asset_ids and context_asset_ids partition asset_ids. Read a record’s claim_scope, association_evidence and confusion_check before comparing. Different views of one project are complementary, not independent examples.

Main instructions and all guides retain Chinese counterparts. The materials folder is shared once, without translated duplicates. Local images and records can be read offline; external links provide provenance and optional fresh verification.

## Use without a network connection

Read the candidate guide, use the matching style note, inspect the actual local images, then compare the nearest alternatives. State missing evidence instead of filling it from memory. If only text is accessible, disclose that the images were not inspected. Image possession and public preview visibility are not reuse licenses; consult the linked records before reuse.

The optional [validator](../scripts/validate_offline.py) checks file hashes, local links, role partitions and recorded fields with network calls disabled. It does not test a model’s recognition accuracy or prove the editorial classifications.
