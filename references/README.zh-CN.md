# 美学设计参考手册

36 篇独立指南先说明归属判据，再解释设计实践。

1. **归属判据：**核心证据、组合判断、替代解释，以及成立、反例和边界案例。
2. **理念与实践设计：**历史背景、设计思想、视觉语言，以及平面、产品、空间和界面的当代转译。

六大分组用于检索，不是互斥的艺术史类别。条目涵盖学校、运动、时期、地域传统、审美观念与市场标签。包豪斯指历史学校及其影响；“中式”范围更广，因此本套内容提供宋代器物、文人水墨、明式家具、宫廷装饰与新中式等具体入口。36 个条目及所选分支均未穷尽设计史。

执行工作流见 [SKILL.zh-CN.md](../SKILL.zh-CN.md)。本手册展开推理与案例。视觉比较从[素材入口](../materials/README.md)和[目录](../materials/catalog.json)开始。每篇指南链接`materials/styles/`下的同编号说明，列明真实作品、出处、可见证据、分支与边界。按目录素材编号找到实际本地图片及记录。中英文版本共享同一素材。本地图片可离线查看；只有外部候选或图片缺失时，须明确视觉证据缺口。外部引用用于溯源与可选扩充，不证明网页、图片已被查看。

## 1. 归属方法：先界定对象，再命名风格

### 1.1 界定对象与问题

说明证据涉及一把椅子、整间展厅、海报版式还是整个网站。不要从一个角落推断全屋，也不要从产品照片推断网站整体版式。

区分三类问题：

- **历史身份：**是否为与某学校、运动、时期或地域相关的原设计或原作？检查相关记录。
- **当代形式语言：**成品使用哪些可观察的组织关系？比较可见结构。
- **实际过程或影响：**创作者是否使用某个参照或工坊方法？因果主张需要过程或文献证据。

未标注输入先记录可见关系，再提出候选。有标签输入应对合理替代解释检验标签，不从结论出发。需要时扩读；方向在本套内容之外时，应承认覆盖限制，不硬套已有风格。

### 1.2 区分可见特征与待验证事实

线条、色面、构件连接、图文层级、重复纹样与空间序列可能直接可见。

年代、作者、机构联系、真实技法、材料成分、自然老化与创作参照，需要馆藏记录、研究、物质证据或过程文献。截图不能独自确定这些事实。

证据必须对应被判对象。设计师曾在某校就读，或博物馆收藏了其早期作品，都不意味着每件后期作品属于同一历史机构。

### 1.3 分别回答历史身份与形式语言

历史身份方面：

- **归属已证实：**指出支持设计或作品身份的记录，例如年代和工坊文献。
- **历史证据不足：**说明缺少哪项作者、日期、委托或研究记录。
- **直接反证：**准确说明记录反驳哪项身份主张。
- **原设计与眼前实物：**可靠记录显示制造于 2026 年时，不能称该实物为 1925 年原物。它仍可能是历史设计的后期生产或复刻。原设计、后期量产、现代复刻、授权与真伪是不同主张。

形式语言方面，将组织关系与指南核心证据、相关历史实例比较。视觉比较不要求事先拿到创作者参考清单；若声称作者实际使用了该参照，仍需单独证据。

历史归属可以已证实而当前实物来源未知；形式语言可以清楚而实际创作影响无记录。

### 1.4 找出组织关系并比较近邻

用各篇证据表，指出哪些结构、比例、构件、纹样或图文关系共同支配主体。不要简单清点颜色、材质或符号。

追问：

- 最接近的相邻风格能否解释同一作品？
- 关键关系改变时，哪条结论会变化？
- 转译到另一媒介后，该关系是否仍成立？
- 候选与近邻是重叠类别，还是更宽与更窄的描述？

装饰可以组织画面；去装饰不是通用归属测试。漂亮、昂贵、好用或材料真实，不代表风格合格。组织拙劣的模仿仍可能可见某风格，而精良对象可能不属于其广告类别。

### 1.5 表述证据、结论与未知项

以下术语用于明确对象和范围的**形式归属**。历史身份和实际影响另答。缺少信息不是反证。

| 形式结论 | 适用情形 | 最少需要解释 |
|---|---|---|
| **主要风格** | 可辨认规则共同支配主体 | 哪些关系、在哪些部位，以及为何有依据采用更具体的归类；“主要”指覆盖与支配作用，不指质量 |
| **局部借鉴** | 区域、图形或构件对应语言，但不支配全局 | 借用什么、整体由什么组织；只有配色相似时就称配色相似 |
| **混合** | 两套以上规则有明确作用 | 说明各自位置，如何分工或共同约束同一结构；两个关键词不能证明融合 |
| **不支持归类** | 主体可见关系与形式主张冲突，或有直接反证 | 指出具体冲突，只限已检查范围；历史身份与年代另行判断 |
| **证据不足** | 输入不能区分合理形式解释 | 缺少的全景、构件细部、平面图或内容；仅缺年代不会推翻充分的形式比较 |

这些是工作用语，不是官方认证或“特征命中足够多”的计分。可用性、无障碍、制作和审美质量仍是不同问题。

实用形式结论可写为：“针对【对象或范围】的【视觉层面】，结论是【术语】，因为【关系与证据】；它与【近邻】的关系是【差异、重叠或未解决的歧义】；相关缺失证据是【如有】。”如果只写出“干净、显贵、精致、有中国元素”，应回到证据表。

## 2. 比较演示：红黄蓝网格究竟能证明什么？

以下三案是**自拟演示**，不是有档案记录的历史委托项目。先看输入的实际视觉与文献事实，不从标签倒推。

| 输入与关键变化 | 结论 | 证据与未解决主张 |
|---|---|---|
| **案例 1：2026 年课程海报。**含红黄蓝色块。时间栏、课程名和说明沿共同轴线对齐；字级、字重编码层级；照片贴合栏系。系列中的长标题仍在同一栏系重排。 | **以[瑞士国际主义](01-rational-modern/03-swiss-style.zh-CN.md)排版为主。**三原色不能独自证明[包豪斯](01-rational-modern/01-bauhaus.zh-CN.md)或[风格派](01-rational-modern/02-de-stijl.zh-CN.md)。 | 主导系统是分栏、字体信息编码和图文对齐。网格与三原色只是共享线索。实际参照仍未知；给定年代说明它是当代作品，而非历史运动原作。 |
| **案例 2：改变主导关系。**保留颜色，去掉等宽信息栏，改用不等量、向边缘延伸的正交线面。文字退为角落次要说明；非具象色面的大小、方向与空隙张力建立非对称平衡。 | **以[风格派式](01-rational-modern/02-de-stijl.zh-CN.md)形式语言为主。**原先瑞士式信息层级不再支配对象。 | 主导关系从信息编码变为线面与空隙的抽象制衡。分界不来自换颜色或换标签。这仍是当代形式比较，不是历史运动身份。 |
| **案例 3：证据残缺与错位归属。**只见裁切图，文字和版式不清。文件名写着“Bauhaus 1923”；附有真实馆藏链接，但记录描绘另一件对象。 | **历史证据不足。**只描述可见形式局部；文件名和另一真品记录都不能认证截图。 | 历史证据必须对应对象。身份主张重要时，补完整画面及匹配的作者、年代、馆藏记录。 |

**有记录的对照：**[包豪斯指南](01-rational-modern/01-bauhaus.zh-CN.md)讨论玛丽安娜·勃兰特茶壶，使用银色金属与深色乌木，没有红黄蓝。记录确定约 1924 年设计和包豪斯金属工坊背景；壶身、壶嘴和隔热把手也分别构成容纳、倾倒、握持的清楚几何部件。因此三原色既非充分证明，也不是有记录的包豪斯原作的必要条件。在售的某把茶壶仍须有自身制造与来源证据。

## 3. 阅读与实践设计

1. **先界定现实问题：**媒介、受众与核心任务，例如五秒内找到展览报名。
2. **按判据 → 理念 → 语言 → 方法阅读：**在挑选视觉处理前，先确定证据与误导表象。
3. **把思想变成可检查动作：**明确对齐、构件连接、顺序和图文职责，不只收集色卡与复古素材。
4. **针对媒介转译：**历史家具、建筑与绘画未规定数字控件。本套界面建议是当代转译，须保持交互可读、可用。
5. **测试真实内容与语境：**尽可能使用实际长短文、产品图片、材料样本或操作流程。披露样例内容和未测状态。
6. **验证成品：**返回归属工作流，指出实际证据，比较近邻，修正无支持的主张或设计决策。必要目标风格仍未满足时，说明要求尚未完成。

每篇指南有九个部分：**归属判定标准、定位与背景、设计理念、设计语言、实践设计方法、设计示例、代表案例与应用边界、相近风格与常见误读、来源**。

标为“自拟”的案例演示推理或转译，不是历史项目。判据、色彩与字体建议、界面规则是实践指导，不是通用历史规范。
